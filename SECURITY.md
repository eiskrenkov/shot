# Security Policy

## Supported versions

Security fixes are made for the latest release of Shot only. Please update before reporting an issue.

## Reporting a vulnerability

Please **do not** open a public issue for security problems. Instead, report them privately through
[GitHub Security Advisories](https://github.com/eiskrenkov/shot/security/advisories/new), or by email to
**egor@iskrenkov.me**.

Include a description of the issue, steps to reproduce it, and the Shot and macOS versions you used.
You should receive a response within a few days. Once the issue is confirmed, a fix will be released as soon as
possible and you will be credited, unless you prefer otherwise.
